I'm interested in the intersection of machine learning and virtual reality. Specifically, I'm interested in how machine learning can be used to provide more information about the location of a user's body than what is provided through headset and controller tracking alone. Or, if I want to sound cool, I like machine learning and biokinetics.

My research so far comes from an undergraduate research project, which you can take a look at [here]({{ site.url }}/research/VR-Elbow-Inference). This project was not as conclusive as I expected when I began, but it gave me the tools, knowledge, and passion to continue this work post-graduation.

This page will be updated as my research progresses.
